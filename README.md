# Amazon Music Connector for Hitster

Scan a [Hitster](https://hitstergame.com) card with your phone and the song plays on Amazon Music. Amazon Music has no public search API for private accounts, so both products use what is on the screen or in the player.

| Folder | What it is |
| --- | --- |
| [amazon-app-android-connector](amazon-app-android-connector) | The Android app. It plays through the Amazon Music app of the same phone. Play Mode, Quiz Mode, Reader Mode, player controls, start at 20 s. |
| [amazon-web-desktop-connector](amazon-web-desktop-connector) | The Desktop connector. The phone talks to a helper on a computer and a Firefox add-on drives the Amazon Music web player. |
| [card-sets](card-sets) | The card sets (CSV) and their names, used by the Android apps. |

Each folder has its own README with the build steps.
