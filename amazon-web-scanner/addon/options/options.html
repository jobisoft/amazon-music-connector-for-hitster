Install the helper app

The add-on cannot read the web page and listen for scripts on its own. It needs the small Python helper app (Python 3 is required). Register it once:

  1. Open the folder native-messaging-app of the Amazon Web Scanner source.
  2. Double-click install.bat and answer y.
  3. Run bash install.sh in a terminal and answer y.
  4. Restart Firefox, load the add-on again and open this page.
